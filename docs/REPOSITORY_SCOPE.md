# 仓库公开范围

## 包含

- `src/meme_radar/`：只读雷达核心、适配器、存储、策略、通知和健康检查。
- `tests/`：解析、策略、RPC边界、存储、outbox和sidecar测试。
- `config/`：不含凭据的策略配置。
- `deploy/systemd/`：需按环境审查的服务模板。
- `.env.example`：空值配置字段。
- `docs/`：稳定架构、策略、安全、部署和运维说明。

## 排除

- `.env`、凭据、RPC Token和Telegram配置；
- SQLite数据库、WAL、health、日志和生产备份；
- 钱包、私钥、助记词和签名材料；
- 自动交易或狙击执行工具；
- VPS地址、本机路径和内部资产清单；
- 会话交接、个人记忆和一次性事故证据；
- 第三方压缩包、依赖缓存和 `node_modules`。

## 发布前检查

每次公开发布至少执行：

1. 全量测试；
2. 凭据与高熵字符串扫描；
3. URL、IP、邮箱和本机绝对路径扫描；
4. `git status` 文件清单复核；
5. 从干净克隆运行一次测试。
