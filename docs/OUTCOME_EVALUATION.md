# 后验效果评估

实时门控只能记录“为什么推送或拒绝”，不能证明策略是否有效。Outcome层在不影响实时决策的前提下，冻结候选并测量后续市场表现。

## 三类样本

- `delivered`：最终 `strong + pass`，全量纳入。
- `evaluated_rejected`：完成统一硬门但被拒绝，全量纳入，用于衡量门槛选择性。
- `not_evaluated`：因预算或时效未完成分析，只做确定性抽样，单独衡量覆盖缺口。

三类样本不能混成一个收益指标，否则大量未评估事件会掩盖安全门的真实效果。

## 时间点

从真实读取到基线价格的时间开始，测量：

- T+1分钟
- T+5分钟
- T+15分钟
- T+1小时
- T+6小时
- T+24小时

每个时间点有允许延迟；超出窗口记为 `expired`，不能伪装成目标时间点。

## 缺失不是零

无交易对、无价格、供应商错误和过期分别记录为 `unavailable`、`error` 或 `expired`，价格保持NULL。缺失观测不能当作价格归零。

## 隔离边界

Outcome collector只写cohort与outcomes表，不修改事件、决策、评分或Telegram outbox。报表以只读模式打开数据库，任何统计结论都不能自动调整生产阈值。
